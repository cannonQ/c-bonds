# c-bonds — Conforming Bond Standard (Phase 1)

A script-ownable bond standard for Ergo: the lender slot holds arbitrary
ErgoTree bytes (`R8: Coll[Byte]`) instead of a `SigmaProp`, so contracts —
vaults, funds, DAOs — can be the lender of record. Signatureless
post-maturity liquidation, on-chain settlement receipts, and a per-loan
token identity.

**Prior art.** The bond/order semantics descend from SigmaFi's
`BondContractERG` by [SigmaBonds](https://github.com/K-Singh/Sigma-Finance),
whose deployed contract proved the P2P fixed-term bond model on mainnet.
This repository is an original implementation (new lineage, no forked
code); the lender-script slot, receipts, schedule pack, and checkpoint
machinery are the additions that make bonds composable. The
settlement-receipt convention follows Duckpools' repayment pattern.

## Status

Phase 1 of the build plan (`conforming-bond-build-plan.md`): order
contract, bond contract with script lender slot, signatureless
liquidation, settlement receipts, deployed to mainnet with dust loans,
plus the Phase 1 adversarial suite. Later phases (checkpoints, covenant
pricing, installments, vault, keeper) build on this without changing the
register layout.

## Register layout (locked)

Bond box:

| Reg | Type | Content |
|---|---|---|
| R4 | `Coll[Byte]` | originating order box id (== loan token id) |
| R5 | `SigmaProp`  | borrower |
| R6 | `Long`       | repayment amount (nanoERG) |
| R7 | `Int`        | maturity height |
| R8 | `Coll[Byte]` | lender ErgoTree bytes |
| R9 | `Coll[Long]` | `[installment, periodBlocks, paymentsRemaining, nextCheckHeight, maintenanceThresholdBps, escrowBalance]` |

A bullet loan is `installment = 0` with a single principal payment at
maturity. Exit outputs carry `R4 = SELF.id` plus the loan token as the
settlement receipt.

**Conforming rule (registry side):** a loan is conforming iff its loan
token id resolves to a box at the conforming order address. Token ids are
minting-tx first-input box ids, and the order contract requires itself to
be `INPUTS(0)` at match, so this provenance cannot be forged
(`src/main/scala/bonds/Provenance.scala`).

## Running

Requires sbt, JDK 8+, and a mainnet Ergo node with `extraIndex = true`.
The harness signs locally and uses only public node endpoints — no node
API key, no node wallet.

```bash
cp .env.example .env                     # then set NODE_URL if not local
sbt "runMain bonds.Contracts"            # compile gate: addresses + sizes
sbt "runMain bonds.GenWallets"           # fresh DUST-ONLY mnemonics -> .env
# fund the printed BORROWER address with ~0.5 ERG, then:
sbt "runMain bonds.Fund"                 # distribute to lender + keeper
sbt "runMain bonds.RunPhase1"            # full Phase 1 suite on mainnet
```

Individual tests: `sbt "runMain bonds.T1_FundFromOrder"` … `bonds.A7_ReceiptOmitted`.

**Dust only.** Test wallets never hold more than dust; nothing above dust
moves until the Phase 6 audit is clean. `.env` is gitignored and
`GenWallets` refuses to write secrets unless that is verified.
